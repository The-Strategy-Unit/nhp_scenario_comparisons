## Introduction and purpose

Welcome to the New Hospital Programme (NHP) scenario comparison tool.
This tool allows NHP schemes to compare two demand modelling scenarios against
each other.
This is based on the existing visualisation in the [main outputs app][outputs],
providing side-by-side versions of the visualisations and figures therein.
The documentation for the demand model is available on the NHP
[Project Information website][proj_info].

[outputs]: https://connect.strategyunitwm.nhs.uk/nhp/outputs/
[proj_info]: https://connect.strategyunitwm.nhs.uk/nhp/project_information/

## Instructions

To use the app, please first select which scheme’s results you wish to view.

Select one model scenario ('Scenario 1') from the drop-down list, then select
the second model scenario you wish to compare with ('Scenario 2').

If needed, use the 'runtime' drop-downs to specify a specific model run, if
there are multiple runs with the same scenario name.

## Content

We provide the following comparisons:

-   Summary (of projected change in activity)
-   Length of Stay
-   Waterfall
-   Activity avoidance impact
-   Efficiencies impact
-   P10-P90 intervals
-   Beeswarm
-   S-curve

Detail on interpretation can be found on the respective tabs.
