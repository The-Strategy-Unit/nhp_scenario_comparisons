## Model version restriction

The New Hospital Programme (NHP) demand model has changed over time, preventing
comparisons between different model versions.

A key reason for this is that over time [the types of potentially mitigatable
activity (TPMA) included in the model][tpma] have changed.

See [documentation of all TPMAs][ipmit] on the NHP project information site,
along
with detail of [model version updates][updates].

We only allow comparisons between scenarios that used the model at version v3.1
or later, as this represented a step change in the modelling methodology
regarding activity avoidance TPMAs.
Please see the [relevant guidance][v3.1].
